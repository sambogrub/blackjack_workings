# Blackjack
 Learning to make a blackjack game using python and tkinter, as well as Pillow for image processing.

 ## Requirements
  - Python **3.11.7**
  - The 'Pillow' library
  - The dependent folder containing card images, see below

## Installation

1. **Ensure you have Python 3.11.7 installed:**
   - [Download Python 3.11.7](https://www.python.org/downloads/release/python-3117/)
   - Verify installation by running:
     ```bash
     python --version
     ```

2. **Install the required library (`Pillow`):**
   - Use pip to install `Pillow`:
     ```bash
     pip install Pillow
     ```

3. **Download or prepare the image folder:**
   - Ensure you have a folder named `images` in the program's directory.
   - Place all required images inside the `images` folder.
